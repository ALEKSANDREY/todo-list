# Todo List App ✅

A full-featured task management app built with **React** — with user authentication, multiple pages, and centralized state management, styled with **Tailwind CSS**.

## Features

- **User authentication** — login flow backed by a dedicated Auth module, plus a user profile page
- **Todo management** — dedicated Todos page for creating and organizing tasks
- **Multiple pages** — Home, Todos, Login, Profile, and About pages with client-side routing, plus a custom 404 page
- **Centralized state** — app state managed with React Context and reducers
- **Responsive UI** — styled with Tailwind CSS, works on mobile and desktop

## Tech Stack

React · Vite · Tailwind CSS · React Context + useReducer · ESLint · Vercel

## Run Locally

1. Clone the repository:

   git clone https://github.com/ALEKSANDREY/todo-list.git

2. Install dependencies:

   npm install

3. Copy the example env file and fill in your values:

   cp .env.example .env

4. Start the dev server:

   npm run dev
